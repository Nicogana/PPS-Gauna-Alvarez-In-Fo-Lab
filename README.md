# Sobre el Repositorio

Aquí se encuentran almacenados todos los proyectos realizados por los alumnos Nicolás Gabriel Gauna y José Matías Álvarez Colantonio, 
para la materia FIM476 ("Práctica Profesional Supervisada") en el año 2026. 

## Qué incluye

1. Ejemplos ilustrativos para aprender Python, realizados tomando como base los primeros 10 capítulos del libro
   "Python Crash Course: A Hands-on, Project-based Introduction to Programming, 2nd Edition" de Eric Matthes
2. Ejemplos de cómo se usan diversas funciones de OpenCV 5 (detección de rostros, redimensión, captura de video, ajuste de imágenes, etc.)
3. Ejemplos de machine learning (extracción e indexado de datos, entrenamiento de un módelo mediante regresión lineal, etc)
